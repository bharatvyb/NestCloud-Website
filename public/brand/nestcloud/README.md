# NestCloud™ official logo library

These eight original PNG files were supplied by the brand owner. Artwork, proportions, colors and trademark symbols are preserved. All images are 2000 × 2000 px.

## Choose a layout and contrast
- `horizontal`: navigation bars, footer branding and compact headers.
- `stacked`: brand stories, larger illustrations, presentations and identity panels.
- `light`: blue Nest / bright blue Cloud artwork for white and light surfaces.
- `dark`: white Nest / light blue Cloud artwork for navy and dark surfaces.

## Choose a background
- `transparent/`: provided alpha-background originals; preferred for integration into website layouts.
- `solid/`: provided background-included originals, white for light versions and navy for dark versions.

The mapping applies to both source folders. The originals are never overwritten or regenerated. `src/brand.tsx` is the shared asset manifest and component for current and future website uses. It hides only empty canvas margins through CSS while retaining the complete supplied mark, including TM. Do not stretch, recolor, redraw, remove the trademark, or use low-contrast variants.
